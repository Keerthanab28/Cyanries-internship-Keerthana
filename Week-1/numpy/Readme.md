# NumPy Fundamentals

## Overview

Implemented NumPy fundamentals and statistical analysis as part of Week 1 AIML internship work.

## Topics Covered

- 1D, 2D and 3D NumPy arrays
- Array dimensions using `ndim`
- Array shapes using `shape`
- Memory information using `itemsize` and `nbytes`
- Vectorized arithmetic operations
- Mathematical and trigonometric operations
- Boolean comparisons and filtering
- Aggregation functions
- Axis-based operations
- Sorting
- Concatenation and stacking
- Reshaping
- Broadcasting
- Element-wise multiplication
- Matrix multiplication using `@`

## Dataset Analysis

Used the Iris dataset to perform numerical analysis using NumPy.

### Statistics Calculated

- Mean
- Median

- Standard deviation
- Correlation matrix
